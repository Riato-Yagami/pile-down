Pile Down

Pile Down is a fast-paced memory solitaire game about completing descending stacks before time runs out.

Memorize the hidden values, choose the right card, and survive increasingly difficult rounds filled with special rules. Build a powerful collection of bonuses along the way, finish the main challenge, and unlock Endless Mode to chase an even higher score.

How to play

  • Drag a card from your hand onto the stack waiting for that value.
  • Each stack accepts exactly one value below its current card.
  • Placed cards are revealed briefly, then hidden again: remember them.
  • A wrong move or an expired timer costs one life.
  • Complete every stack to clear the round.

Controls

  • Mouse / touch: drag cards, select buttons and adjust audio.
  • Space: start the game or restart after a game over.
  • Escape: return to the main menu; on desktop, press it again to quit.
  • M: mute or restore music and sound effects.
  • T: show or hide the total run time.
